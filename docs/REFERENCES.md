# References used

The interface uses familiar real-estate marketplace patterns—city and property-type browsing, visible sale/resale/rent labels, listing cards, and explicit verification cues—without copying a brand's visual assets or page copy.

## Product and trust patterns

- [PropVerify sample portal](https://propverify.co.in/) — observed city browse, listing categories, and visible trust-signal explanations as interaction-pattern references. No listing data or branding was copied; the sample site is not treated as an authoritative data source.
- [Unsplash image result: apartment facade](https://unsplash.com/fr/photos/un-grand-immeuble-avec-balcon-Z27XMPg9ygM) — visual reference for the sample photo style. The app uses illustrative remote Unsplash image URLs; replace them with imagery the property owner has authorized for publication.

## Official sources

- [India Code: Real Estate (Regulation and Development) Act, 2016](https://www.indiacode.nic.in/indiacode/bitstream/123456789/2158/1/A201616.pdf) — includes project and real-estate-agent registration sections. This app does not determine whether a specific listing or operator is covered.
- [MahaRERA: FAQs, manuals, and guidelines](https://www.maharera.maharashtra.gov.in/sites/default/files/faqs/FAQs-23072019%20%281%29.pdf) — state-specific agent and advertising guidance; check the authority for the state where a real listing will be offered.
- [MeitY: Digital Personal Data Protection Rules 2025](https://www.meity.gov.in/documents/act-and-policies/digital-personal-data-protection-rules-2025-gDOxUjMtQWa?pageTitle=Digital-Personal-Data-Protection-Rules-2025) — official rules resource to consult when preparing a real lead-collection service.
- [OpenAI API: Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses) — official reference for constraining AI search-filter extraction to a JSON schema.

These references inform the UI and engineering choices. They are not legal advice or a verification of demo inventory.
